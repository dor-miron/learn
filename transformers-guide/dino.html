ViT & DINO.

Same attention machinery as language models, but applied to image patches. Then a striking result: train this model with no labels at all, and the attention maps spontaneously become object segmentations.

From images to tokens: the Vision Transformer

Transformers want a sequence of vectors. Images are 2D grids of pixels. So the first job is to turn an image into a sequence. The Vision Transformer (ViT) does the dumbest thing that works: chop the image into a grid of fixed-size patches, flatten each patch into a vector, and call those your tokens.

A 224 × 224 image with 16 × 16 patches gives you a 14 × 14 grid — 196 patch tokens, plus the [CLS] token, plus positional embeddings added to each. That sequence then goes through a standard transformer encoder — exactly the attention blocks from the previous page. Bidirectional attention, no masking, because there’s no notion of “past” in an image.

The CLS token

The [CLS] token is a learnable vector with no content of its own. It carries no pixel information, ever. It is prepended to the sequence so it can attend to all the patches, but no patch is “about” the CLS token specifically.

So why have it? Because we need a single fixed-size vector to represent the whole image — for classification, retrieval, whatever. We could average all patch tokens, but the model can do better than the average if we give it a dedicated slot that’s allowed to gather information freely. Over training, the CLS token learns to summarise the whole image into one vector, and the standard ViT loss only ever reads from this slot.

Key point

The CLS token is a register the model uses to accumulate a global summary. Its job, role, and what it ends up paying attention to are entirely shaped by the training objective. We’ll see what that means for DINO in a moment.

The supervised version (the boring part)

Original ViT is trained the obvious way: feed an image, take the final CLS vector, push through a small classifier, predict the ImageNet label, optimise cross-entropy. It works. It needs a lot of data. It is not particularly interesting.

The interesting question: can you train a ViT without labels at all?

DINO — self-distillation without labels

DINO (Caron et al., 2021) is one answer. The name unpacks as “self-distillation with no labels” (the team had fun with the acronym). The recipe is short:

  1. Create two networks with identical architecture — a student and a teacher. Both are ViTs.
  2. Take an image. Make several augmented crops of it — two large “global” crops and several smaller “local” crops, plus colour jitter, blur, etc.
  3. Show the student all crops. Show the teacher only the global crops.
  4. For every (student-output, teacher-output) pair coming from the same source image, ask the student to match the teacher’s output distribution. This is the loss.
  5. Update the student by gradient descent. Update the teacher as an exponential moving average of the student — no gradients flow to the teacher.

Why this isn’t obviously crazy

At first glance, DINO looks impossible. If the teacher is just a slow copy of the student, what stops both networks from collapsing to the trivial solution “always output the same vector”? That would satisfy the loss perfectly.

Two design choices prevent collapse:

  • Centering the teacher output: subtract a running mean from the teacher’s logits before softmax. This stops any single dimension from dominating.
  • Sharpening the teacher output: use a much lower softmax temperature for the teacher than the student. This makes the teacher’s distribution peaky and the student’s smooth. The student is being asked to match a confident target with a less-confident prediction.

Centering pushes the distribution toward uniform; sharpening pushes it toward one-hot. The two pressures cancel out at some non-trivial equilibrium, and the network has to make actual use of the input to thread that needle.

The loss in one line

For each student-view s and teacher-view t (with t ≠ s) of the same image:

L = − ∑i pt(i) · log ps(i)

i.e. cross-entropy between the teacher’s output distribution (treated as the target) and the student’s output distribution.

So — why does this happen? The argument has three steps:

  1. The CLS token has to produce a vector that’s consistent across crops. The training loss says: whatever the teacher outputs given the global crop, the student must output approximately the same thing given a (potentially much smaller, much more aggressively augmented) crop of the same image.
  2. What is consistent across random crops of an image? The background changes (different parts of the grass visible). The framing changes. The colours wobble (jitter). The identity of the main object — the dog — is roughly the only stable signal across two random crops, because random crops are usually arranged to share the object.
  3. So the model is pressured to base its CLS summary on the object, not the background. The way it does that in a transformer is by attending more to object patches. The CLS-to-patch attention map becomes an object-vs-background map. That is exactly what a segmentation mask is.
The deep version of the point

The model wasn’t taught segmentation. It was taught “same-image crops should produce the same summary vector.” The only solution to that constraint that generalises is “ignore the parts of the image that vary between crops, focus on the parts that don’t.” And the parts that don’t vary are the object. Segmentation is the path of least resistance through the loss.

How training shapes the CLS token specifically

Reading order matters here. The CLS token starts as a learnable vector of essentially noise. In early training, it has no idea what to attend to, and its attention map looks roughly uniform — every patch contributes about equally. As gradients flow:

  • The patches that help the CLS match the teacher across crops get attended-to more. Their contribution gains weight.
  • The patches that vary uselessly across crops (background, distractors) become a liability — attending to them makes the CLS jitter. They get attended-to less.
  • By late training, the CLS attention map is concentrated on the persistent semantic content — the object.

This is why people sometimes describe DINO as “learning what objects are without being told.” The loss is just “match the teacher”, but the path through that loss runs through the concept of object-ness.

Why ViT (not a CNN) makes this so visible

A CNN trained with a similar self-distillation recipe also learns useful features, but you can’t just read a segmentation map off its last feature map. ViTs are different in a useful way:

  • Every layer’s attention is a literal N × N matrix of weights between patches. You can pluck out the CLS row and reshape it to the image grid. It is directly a heatmap over the input.
  • The CLS is the only mandatory aggregator, so the model has to put its summary there — you can’t hide information in a global average pool, because there isn’t one.

One more thing: this is not classification

Notice what the “output distribution” ps, pt in the loss actually is. There’s no class set. The projection head produces a vector of, say, 65 536 numbers, which is softmaxed into a distribution over nothing in particular. The dimensions don’t correspond to dogs, cats, or anything. They’re just a place for the model to lay out its features. The only constraint is “different views of the same image must produce similar distributions, and over the dataset the average distribution must be reasonably spread out (centering).”

What ends up emerging in that 65 536-dim distribution is something like a prototype index — clusters that correspond, post-hoc, to recognisable semantic categories. But the model was never told about them.

DINOv2 in one paragraph

The 2023 follow-up (DINOv2) keeps the self-distillation core and scales it up — much more data, careful data curation, bigger ViTs, plus an additional iBOT-style masked patch prediction loss alongside the CLS-distillation loss. The result is a foundation model whose frozen features are competitive with supervised ones on basically every dense-prediction task: depth, segmentation, retrieval, fine-grained classification. The mechanism is the same; the engineering is heroic.

Recap

  • A ViT cuts an image into patches and treats each as a token. A learnable [CLS] token is prepended to serve as a global summary slot.
  • DINO trains a ViT with no labels by self-distillation: a student matches the output of a slow-moving teacher copy of itself, across different augmented crops of the same image.
  • Centering and sharpening keep the system from collapsing to a constant output.
  • Segmentation emerges because the only way to produce a consistent CLS summary across crops is to attend to the parts of the image that don’t change — the object — and downweight everything else.
  • The CLS’s last-layer attention map, read directly, is a usable object mask.
