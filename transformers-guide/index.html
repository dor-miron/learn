A focused tour of the ideas behind modern deep learning — written for someone who wants to build solid mental models, not memorise PyTorch incantations. Each page stands alone, but they build on each other.

If you have time, read in order. The attention page builds the vocabulary every other page leans on. If you only care about a specific topic, each page is self-contained and the cross-references are explicit.
